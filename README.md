# Davi Nicacio — Front-End Developer Portfolio

Portfólio pessoal de **Davi Nicacio de Oliveira Cunha**, desenvolvedor front-end focado em criar soluções web, desktop e mobile eficientes, responsivas e intuitivas.

---

## ✨ Sobre o projeto

Site pessoal em estilo dark-mode, minimalista, com tipografia forte, microinterações e animações de scroll-reveal — pensado para apresentar experiência profissional, stack técnica e projetos de forma direta e visualmente marcante.

### Seções

- **Hero** — apresentação com headline animada e CTAs para projetos e contato
- **Sobre** — bio + grid de tecnologias por categoria
- **Timeline** — linha do tempo com experiência profissional e acadêmica
- **Projetos** — cards com descrição, tags de tecnologia e links, com modal de galeria de mídia (imagens/vídeos) navegável manualmente
- **Contato** — CTA final com links diretos para WhatsApp, e-mail, LinkedIn e GitHub

## 📦 Como rodar localmente

Pré-requisitos: [Node.js](https://nodejs.org/) e npm instalados (recomendado usar [nvm](https://github.com/nvm-sh/nvm) para gerenciar versões).

```sh
# Clone o repositório
git clone https://github.com/daviniccacio/davinicacio-dev-showcase.git

# Entre na pasta do projeto
cd davinicacio-dev-showcase

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev
```

O site abrirá em `http://localhost:5173` (ou porta equivalente informada no terminal).

### Build de produção

```sh
npm run build
```

Os arquivos finais são gerados na pasta `dist/`.
